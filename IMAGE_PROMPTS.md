# Next Generation Apparel — Product Image Prompts

A ready-to-use prompt for every product in the catalog. Works in Midjourney, DALL·E, Adobe Firefly, Ideogram, or any text-to-image tool.

## How to use these

Each product below has a base prompt describing the garment. To make the color variants your store already lists, just swap in the color word at the front (the colors for each piece are noted in brackets).

Recipe: [COLOR] + [base prompt] + [STYLE BLOCK]

Keep the STYLE BLOCK identical on every image so the whole grid looks like one consistent shoot.

### Style block (append to every prompt)

> flat-lay product photography, single garment laid flat and neatly arranged on a smooth bone-white seamless paper backdrop, perfectly top-down overhead angle, soft even diffused studio lighting, true-to-life fabric texture, subtle natural shadow, centered with generous negative space, no model, no hanger, no props, no text or logos, color-accurate, high resolution, premium e-commerce catalog style

### Settings
- Aspect ratio: 3:4 (portrait) — matches the new card layout. In Midjourney add --ar 3:4.
- Consistency: shoot/generate all 40 on the same backdrop and angle. In Midjourney, reusing a --sref (style reference) across all images keeps lighting uniform.
- Two views (optional): the store supports a hover image. Generate a second angle ("...slightly angled three-quarter overhead view, gently folded") and drop it in as img2.

## Dropping images into the site

In the site's PAL object, add an img (and optional `img2`) to each color. Example for the tee palette:
```js
tee:[
 {name:'White', hex:'#F1EFE9', img:'images/tee-white.jpg', img2:'images/tee-white-2.jpg'},
 {name:'Black', hex:'#1C1A17', img:'images/tee-black.jpg'},
 {name:'Sand', hex:'#C9B79B', img:'images/tee-sand.jpg'},
 {name:'Sage', hex:'#9AA587', img:'images/tee-sage.jpg'}
],
```

Any color without an img keeps showing the vector illustration, so you can roll photos in gradually.
