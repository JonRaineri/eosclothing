# Next Generation Apparel - Website Build

Fashion e-commerce storefront. Vanilla HTML/CSS/JS, no framework.

## Architecture
- Single-page static site
- SVG garment illustrations with CSS color swatching (recolorable via `--fabric`)
- Support for real product photos (add `img`/`img2` to color entries)
- Filter by gender (Women/Men) + type (Tops/Bottoms)
- Sort: featured, price low/high, alphabetical
- Cart drawer with quantity controls, shipping progress bar
- 40 products across 9 silhouettes

## Color Palette
- Paper: #F6F4EF (warm off-white)
- Ink: #1A1815 (near-black)
- Oxblood: #7A2E33 (accent/CTA)
- Stone: #B6AE9F (muted)
- Fonts: Bodoni Moda (display) + Hanken Grotesk (body)
